# Services Required

## Core Azure Services

1. **Microsoft Azure Subscription** – Provides the cloud environment for deploying and managing resources.
2. **Azure Resource Group** – Organizes the resources used in the project.
3. **Azure Resource Locks** – Provides protection against accidental deletion or modification of resources.

## Supporting Azure Services

4. **Azure Storage Account** – Used as the protected sample resource.
5. **Azure Virtual Network** – Provides network infrastructure for the Azure environment.
6. **Azure RBAC** – Controls user and administrator access to Azure resources.
7. **Azure Activity Log / Azure Monitor** – Used for monitoring and auditing resource operations.

## Optional Future Enhancements

8. **Azure Policy** – Can enforce governance rules across Azure resources.
9. **Azure Bicep / Terraform** – Can automate infrastructure deployment and configuration.
