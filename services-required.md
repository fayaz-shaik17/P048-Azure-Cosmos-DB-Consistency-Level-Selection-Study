# Services Required

Core Services
Azure Cosmos DB – Main database service and consistency-level configuration.
Azure Subscription – Provides the Azure cloud environment and resource management.
Azure Resource Group – Organizes all project resources.

Supporting Services
Azure Monitor – Monitors latency, metrics, logs, and performance.
Azure Functions – Can be used to simulate different workload/access patterns.
Azure Portal / Cosmos DB SDK – Used for database configuration, data access, and testing.
Azure Storage Account – Optional, for data ingestion or storing test results.

Optional/Future Services
Azure Data Factory – Automated data pipelines and testing.
Azure Logic Apps – Workflow automation.
Azure Bicep / Terraform – Infrastructure-as-Code deployment.
Azure Key Vault – Secure storage of credentials and keys.
